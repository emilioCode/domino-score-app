## 🇪🇸 Español

### 1. Información general

**Dominó Score** es una aplicación móvil desarrollada por **HMT - Hernandez Mendez Tecnología**. Esta política de privacidad describe cómo se maneja la información dentro de la aplicación.

### 2. Datos que NO recopilamos

Dominó Score **no recopila, almacena ni transmite** ningún dato personal a servidores propios. No existe:

- Registro de usuarios ni creación de cuentas
- Inicio de sesión
- Seguimiento de ubicación
- Recopilación de correos electrónicos u otros datos de identificación personal

### 3. Datos almacenados localmente

La aplicación guarda cierta información **únicamente en el dispositivo del usuario** mediante AsyncStorage (almacenamiento local del dispositivo):

| Dato | Propósito |
|---|---|
| Nombres de equipos | Personalizar la partida en curso |
| Historial de partidas | Mostrar resultados de partidas anteriores |
| Preferencia de tema (claro/oscuro) | Recordar la configuración visual del usuario |

Estos datos **nunca salen del dispositivo** y pueden eliminarse desinstalando la aplicación.

### 4. Publicidad — Google AdMob

Dominó Score utiliza **Google AdMob** para mostrar anuncios. AdMob es un servicio de publicidad de Google LLC.

Google AdMob puede recopilar y procesar ciertos datos para mostrar anuncios relevantes, incluyendo:

- Identificadores de dispositivo (IDFA en iOS / GAID en Android)
- Datos de uso e interacción con anuncios
- Dirección IP aproximada

Este procesamiento de datos está sujeto a la **Política de Privacidad de Google**, que puedes consultar en:
[https://policies.google.com/privacy](https://policies.google.com/privacy)

Para más información sobre cómo Google usa los datos en publicidad:
[https://policies.google.com/technologies/ads](https://policies.google.com/technologies/ads)

### 5. Permisos

Dominó Score no solicita permisos especiales del dispositivo (cámara, micrófono, contactos, ubicación, etc.).

### 6. Menores de edad

Esta aplicación no está dirigida a menores de 13 años. No recopilamos conscientemente datos de niños.

### 7. Cambios a esta política

Podemos actualizar esta política ocasionalmente. Cualquier cambio se reflejará en este documento con una nueva fecha de actualización.

## 🇺🇸 English

### 1. General Information

**Dominó Score** is a mobile application developed by **HMT - Hernandez Mendez Tecnología**. This privacy policy describes how information is handled within the application.

### 2. Data We Do NOT Collect

Dominó Score **does not collect, store, or transmit** any personal data to our own servers. There is no:

- User registration or account creation
- Login system
- Location tracking
- Collection of email addresses or other personally identifiable information

### 3. Locally Stored Data

The application saves certain information **exclusively on the user's device** using AsyncStorage (local device storage):

| Data | Purpose |
|---|---|
| Team names | Personalize the current game |
| Game history | Display results from previous games |
| Theme preference (light/dark) | Remember the user's visual settings |

This data **never leaves the device** and can be removed by uninstalling the application.

### 4. Advertising — Google AdMob

Dominó Score uses **Google AdMob** to display advertisements. AdMob is an advertising service provided by Google LLC.

Google AdMob may collect and process certain data to serve relevant ads, including:

- Device identifiers (IDFA on iOS / GAID on Android)
- Usage data and ad interaction data
- Approximate IP address

This data processing is governed by **Google's Privacy Policy**, available at:
[https://policies.google.com/privacy](https://policies.google.com/privacy)

For more information on how Google uses data for advertising:
[https://policies.google.com/technologies/ads](https://policies.google.com/technologies/ads)

### 5. Permissions

Dominó Score does not request any special device permissions (camera, microphone, contacts, location, etc.).

### 6. Children's Privacy

This application is not directed at children under the age of 13. We do not knowingly collect data from children.

### 7. Changes to This Policy

We may update this policy from time to time. Any changes will be reflected in this document with a new update date.
